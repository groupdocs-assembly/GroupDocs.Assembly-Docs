## Column Chart in Microsoft PowerPoint Document

### Creating a Column Chart

Please follow below steps to create a column chart in MS PowerPoint 2013:

1.  Create a new presentation slide
2.  Click the "Insert" tab, and then click "Chart" in the illustrations group to open the "Insert Chart" dialogue box
3.  Select "Column" in the sidebar, you will see a gallery of charts
4.  Select the "100% Stacked Column" and press "OK" to insert the chart and Worksheet template to your document
5.  Edit the Worksheet with your data to update the chart
6.  Save your Document

### Reporting Requirement

As a report developer, you are required to share orders quantity of the customers dynamically with the following key requirements:

*   Report must show quantity of sales/orders
*   Sales/orders quantity must be represented by Quarters
*   It must associate order quantity with the corresponding customer
*   Report must be generated in the Presentation Document

```python
import json
from datetime import datetime

from groupdocs.assembly import DataSourceInfo, DocumentAssembler

def parse_dates(item):
    # JSON has no dates: turn the order dates into datetime objects for the template
    for key in ("OrderDate", "ShippingDate"):
        if key in item:
            item[key] = datetime.strptime(item[key], "%Y-%m-%dT%H:%M:%S")
    return item

with open("orders.json", encoding="utf-8") as f:
    orders = json.load(f, object_hook=parse_dates)

assembler = DocumentAssembler()
assembler.assemble_document("chart-with-filtering-and-dynamic-title.pptx", "chart-with-filtering-and-dynamic-title-report.pptx", [
    DataSourceInfo(orders, "orders"),
    DataSourceInfo("Harbor Lane orders by customer, 2015", "title"),
])
```
