Each page here answers one whole question — the design, the code that runs and the parts that are
easy to get wrong — and links to a repository you can clone and run.

* [Generate documents from model output]({{< ref "/assembly/net/use-cases/generate-documents-from-llm-output.md" >}}) — a language model returns JSON, a template turns it into the document you send.
* [Generate a Word report from a template]({{< ref "/assembly/net/use-cases/generate-word-report-from-template.md" >}}) — the shortest path from an object or a JSON file to a DOCX and a PDF.
* [Templates for incomplete data]({{< ref "/assembly/net/use-cases/templates-for-incomplete-data.md" >}}) — a JSON Schema as the contract, and the two options that decide what a missing member does.
* [Generate Excel reports from a template]({{< ref "/assembly/net/use-cases/generate-excel-reports-from-template.md" >}}) — a workbook that stays a workbook: native numbers, repeated rows, formulas that still work.
* [Generate presentations from JSON]({{< ref "/assembly/net/use-cases/generate-presentations-from-json.md" >}}) — a deck built from data, with a picture in every table row.
* [Generate reports in ASP.NET Core]({{< ref "/assembly/net/use-cases/generate-reports-in-aspnet-core.md" >}}) — JSON in, a file out, and a preview of the first page.
* [Running in Docker and serverless]({{< ref "/assembly/net/use-cases/running-in-docker-and-serverless.md" >}}) — the Linux image, the fonts it needs and how to prove they are there.
