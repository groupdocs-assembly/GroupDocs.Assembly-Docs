Each page here answers one whole question — the design, the code that runs and the parts that are
easy to get wrong — and links to a repository you can clone and run.

* [Generate Word documents from LLM output]({{< ref "/assembly/net/use-cases/generate-documents-from-llm-output.md" >}}) — a language model returns JSON against a schema, a template turns it into the document you send.
* [Generate a Word document from a template]({{< ref "/assembly/net/use-cases/generate-word-report-from-template.md" >}}) — the shortest path from an object or a JSON file to a DOCX and a PDF.
* [Handle missing and null data in templates]({{< ref "/assembly/net/use-cases/templates-for-incomplete-data.md" >}}) — a JSON Schema as the contract, and the two options that decide what a missing member does.
* [Generate Excel reports from a template]({{< ref "/assembly/net/use-cases/generate-excel-reports-from-template.md" >}}) — a workbook that stays a workbook: repeating rows, native numeric cells and totals that compute.
* [Generate PowerPoint presentations from JSON]({{< ref "/assembly/net/use-cases/generate-presentations-from-json.md" >}}) — a deck built from data, with a picture in every table row.
* [Generate and download reports in ASP.NET Core]({{< ref "/assembly/net/use-cases/generate-reports-in-aspnet-core.md" >}}) — JSON in, a file out, and a preview of the first page.
* [Document generation in Docker and serverless]({{< ref "/assembly/net/use-cases/running-in-docker-and-serverless.md" >}}) — the Linux image, the fonts it needs and how to prove they are there.
