GroupDocs.Assembly for Node.js via Java is a document automation and report generation API. You design a template in Microsoft Word, Excel, PowerPoint, Outlook, OpenDocument, HTML, Markdown or plain text, add template tags that describe how to present your data, and GroupDocs.Assembly builds the final document from the template and your data.

The package `@groupdocs/groupdocs.assembly` wraps GroupDocs.Assembly for Java through the [java](https://www.npmjs.com/package/java) bridge, so it offers the same reporting engine and template syntax as the Java version.

With GroupDocs.Assembly for Node.js via Java you can:

*   Use JSON, XML and CSV files, streams or strings, `DataSet` objects and tables loaded from other documents as data sources
*   Combine several data sources in one template
*   Output values, perform calculations and apply string, number and date-time formatting in template expressions
*   Use a LINQ-based template syntax with lambda functions and enumeration extension methods (`where`, `select`, `groupBy`, `orderBy`, `sum`, `count` and more) for filtering, grouping and sorting
*   Build tables, lists, charts, images, barcodes, hyperlinks, bookmarks and check boxes dynamically
*   Show or hide content with conditional blocks, and apply text and background colors dynamically
*   Insert the contents of other documents into the report
*   Build email messages with dynamic subject, recipients, body and attachments
*   Update fields and recalculate spreadsheet formulas during assembly
*   Remove empty paragraphs automatically
*   Report template syntax errors inline in the generated document instead of throwing exceptions
*   Save the report in the template's format or convert it to another one, for example DOCX to PDF, on the fly

GroupDocs.Assembly for Node.js via Java runs on Windows, Linux and macOS wherever Node.js and Java are available. It does not require Microsoft Office or any other third-party software.
