**GroupDocs.Assembly for Node.js via Java** is a document automation and report generation API for Node.js. It merges a template document with data from JSON, XML, CSV, databases or other documents and produces the result in the template's format or in another output format, such as PDF or HTML. Templates use the same LINQ-based syntax as GroupDocs.Assembly for Java, so you can build tables, lists, charts, images, barcodes, hyperlinks and conditional content from your data.

GroupDocs.Assembly supports [Microsoft Word, Excel, PowerPoint, Outlook, OpenDocument, HTML, Markdown and other formats](/assembly/nodejs-java/supported-document-formats/) as templates and can save reports to PDF, XPS, HTML, images and more.
