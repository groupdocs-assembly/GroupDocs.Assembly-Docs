A bulleted list presents items that are introduced with a bullet symbol ( • ), for example:

*   Item 1
*   Item 2
*   Item 3

To build a bulleted list report, put a `foreach` tag into a bulleted paragraph of the template. GroupDocs.Assembly repeats the paragraph, including its bullet formatting, for every item of the data sequence.
